One dad joke, delivered straight-faced: "My son asked why the moon goes to the bank every month. I told him: it needs to change into quarters." The pun turns on quarters — the moon's phases and the coins a bank gives you in change — with the punchline held to the very last word. The program in `main.ts` (Node 22, standard library only) writes that single joke, byte-identically on every run, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` anywhere else), clearing only the directory's contents first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
